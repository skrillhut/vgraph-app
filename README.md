# VGraph

Простой векторный редактор на Java и Swing. Работает локально, внешние библиотеки не требуются.

## Запуск

Из корневой папки проекта выполните команды. Для сборки нужен JDK с компилятором `javac`.

```sh
javac -encoding UTF-8 -d bin src/*.java
java -cp bin App
```

Для запуска из VS Code откройте проект и нажмите **Run** у метода `main` в `src/App.java`.

## Управление

- Выберите прямоугольник, эллипс или линию и протяните мышью по холсту. Для многоугольника укажите вершины щелчками и нажмите Enter, дважды щёлкните последнюю вершину или щёлкните первую. Escape отменяет незаконченный жест.
- После создания фигура выделена. Перетаскивайте её для перемещения, угловой маркер для изменения размера или конец линии для изменения её длины и направления.
- Кнопки **Заливка** и **Обводка** задают цвета для рисования. При выделенной фигуре они также меняют её цвет. У линии есть только обводка.
- **Удалить** или клавиша Delete удаляет выделенную фигуру. **Отменить** возвращает до пяти последних изменений. Одно перетаскивание считается одним шагом.
- Масштаб внизу окна изменяет вид холста от 25% до 400%. Размер рисунка в проекте и SVG составляет 1000 × 700.
- **Сохранить** записывает редактируемый проект в файл `.vgraph`, **Открыть** восстанавливает фигуры и цвета. **Экспорт SVG** создаёт отдельный векторный рисунок.
- Для отмены, сохранения и открытия доступны Ctrl+Z, Ctrl+S и Ctrl+O. В macOS используйте Command вместо Ctrl.

## Устройство проекта

`Figure` — абстрактный базовый класс. Он реализует работу с цветами, перемещение, масштабирование и проверку попадания мыши. Его наследники `RectangleFigure`, `EllipseFigure`, `LineFigure` и `PolygonFigure` определяют геометрию и представление фигуры в SVG. Линия переопределяет поведение маркеров.

`Drawing` хранит фигуры в порядке отрисовки и ведёт историю. `EditorCanvas` отображает рисунок и обрабатывает действия мыши. `EditorWindow` отвечает за команды интерфейса, а `ProjectFile` — за чтение и запись файлов.
